Corpus note (the two install layouts, as stated in this thread): an `install.sh` install deploys the shell config under `~/.config/quickshell/` and the binaries/scripts under `~/.local/bin/`; the `caelestia-kde` package install uses `/usr/bin` and `/etc/xdg/quickshell/caelestia/` for the shell. When diagnosing path problems, first check which of the two install kinds produced the tree in question.
