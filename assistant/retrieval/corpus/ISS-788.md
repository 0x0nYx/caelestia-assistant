## Problem (original report, condensed)

A feature request: apps (especially Electron apps) publish taskbar badges — unread-notification counts and custom graphics like Discord's red unnumbered dot — and the reporter wanted the Caelestia dock to render them. Key part of the request, verbatim:

> Apps, especially Electron apps can show badges in the taskbar to indicate for example the number of unread notifications. Even custom graphics (like discord's red unnumbered dot when there are no notifications). From my very limited research my understanding was that KDE recieves those, and that in principle, caelestia could make use of them to show them on the taskbar, because currently I don't have those.

(The reporter explicitly hedged that the request might not be caelestia-rooted — "if this issue isn't actually rooted in caelestia, please correct me" — and asked to be told if it was out of scope.)

How it closed: PR #808 "feat(dock): show app badges on dock icons" (opened by 0xSolanaceae, 7 commits, 7 files) was merged 2026-09-22T19:59:27Z (merge commit ec64757e2bd6f155ad099a768efe718134e4d5a5, cross-referenced from the issue's timeline), and the issue was closed as completed by 0xSolanaceae 14 seconds later with the one-word confirmation "added". The PR's own description says: "Implements #788. Apps publish taskbar badge state through the Unity launcher API (`com.canonical.Unity`); a new QML singleton (`LauncherEntry`) listens for it and the dock renders the urgent tint, a count badge and a progress bar on each tile."

Corpus note: dock app badges are a SHIPPED FEATURE since v2.5.0, not a fault. Two honest limits from the collaborator's own resolution: (1) badges only appear for apps that publish the `com.canonical.Unity.LauncherEntry` Update signal on the session bus — "it won't be compatible with all apps. So things like firefox and most KDE/Qt apps won't interact with it at all", so a missing badge on Firefox or a KDE/Qt app is EXPECTED behavior, not a bug to fix; (2) the feature is gated by the per-bar `bar.dock.showBadges` setting (default on, "Show app badges" toggle in Nexus -> Taskbar), so badges can also be deliberately off.
